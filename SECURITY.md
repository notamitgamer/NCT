# Security Policy

## Supported Versions
Currently, only the latest version (v2.11) is actively supported with security updates.

## Reporting a Vulnerability
If you discover a security vulnerability within this project, please send an e-mail to:
- **amit.is-a.dev**
- **amitdutta4255@gmail.com**

Please do not report security vulnerabilities through public GitHub issues. We will acknowledge your report within 48 hours.
